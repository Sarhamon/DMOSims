# 🦖 DMOKit (Digimon Masters Online Kit)

## 📖 소개
> **DMOKit**은 디지몬 마스터즈 온라인(DMO) 플레이어들을 위한 종합 웹 유틸리티 도구입니다.
> 탐험 효율 분석부터 확률형 아이템(뽑기) 시뮬레이션, 옵션 변경 · 돌파 시뮬레이션까지, 스마트한 게임 플레이를 지원하는 다양한 기능을 웹에서 간편하게 제공합니다.

## ✨ 주요 기능
- **🗺️ 탐험 효율 계산기:** Lv.1 ~ Lv.170 탐험지별 경험치 효율과 필요 횟수 분석
- **🃏 데이터 드로우 시뮬레이터:** 공식 확률 기반 드로우 체험, 결과 인벤토리 누적
- **🔮 데이터 소환 시뮬레이터:** 캡슐 기반 소환, 천장(피티) 시스템 포함
- **⚗️ 데이터 융합 시뮬레이터:**
  - 동일 등급 4개 → 결과 1개 합성, 천장(피티) 시스템 포함
  - **자동 / SSS / SSS+** 모드 선택 — 자동은 하위 등급부터 순차 합성, SSS·SSS+ 모드는 해당 등급만 선별 합성
  - 10회 일괄 합성 지원
- **🧩 디지털 융합(모듈) 시뮬레이터:**
  - 모듈 퀘스트 일일 / 주간 보상으로 등급 상자를 받아 열고, 동일 등급 모듈 4개 → 1개 합성
  - 10회 융합: 자동(하위 등급부터) / 등급별 모드
  - 목표 융합: 목표 등급 · 옵션 모듈 1개가 나올 때까지 합성, 재료 부족 시 1주치 자동 수급 후 걸린 주 수 · 비용 표시
- **📊 가챠 확률 보기:** 드로우 / 소환 / 융합 / 모듈 융합 각 풀의 아이템 목록과 확률 정보 조회
- **⚔️ U등급 딜사이클 리포트:** 디지몬과 덱을 고르면 전투 시간(2 · 10분)별 딜사이클, 스킬포인트 투자, 대안 빌드 비교
- **🔧 옵션 변경 시뮬레이터:** 장비(옵션 변경 재봉틀) · 악세사리(옵션 변경 스톤) 옵션 변경, 줄 고정 · 결과 저장 · 비용 계산
- **🎲 돌파 옵션 시뮬레이터:** 실제 돌파 결과를 입력하면 기대값상 최적의 다음 행 추천, 연습 모드 · 주사위 비용 계산
- **🏆 랭킹 던전 교환:** 무한의 투기장 재료 교환과 목표 아이템 제작까지 필요한 주 · 시즌 수 계산
- **✅ 모듈 퀘스트 체크:** 일일(매일 0시) / 주간(화요일 오전 8시) 퀘스트 체크, 자동 초기화
- **📚 유니온 수집 효과:** 완료한 수집 효과를 체크하면 EXP · 속성 보너스 자동 합산

## 🛠 기술 스택
- **Frontend:** HTML, CSS, JavaScript (Vanilla, ES Modules)
- **Data Pipeline:** Python (`tools/` — 원본 데이터 → JS 모듈 변환)
  - `_parse_draws.py`: `_raw_draws.txt` → `js/gacha/drawData.js`
  - `_parse_fusion.py`: `_raw_fusion.txt` → `js/gacha/fusionData.js`
  - `_parse_report.py`: `report/source/` → `js/report/reportMeta.js`, `js/report/data/`
- **Deployment:** GitHub Pages (정적 웹 호스팅)
